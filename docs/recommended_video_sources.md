# 推荐视频素材

本文档列出适合事件相机模拟器使用的高帧率视频素材。选择素材时优先考虑：
1. 真实高速相机拍摄（非插帧），帧率不低于 120 FPS
2. 有明显运动区域，能产生有意义的事件
3. 许可证允许学术使用和修改

## 素材选择建议

为了丰富实验并展示模拟器在不同场景下的表现，建议从以下维度各选至少一段：

| 维度 | 已覆盖 | 建议补充 |
| --- | --- | --- |
| 高帧率 (>= 960 FPS) | 齿轮、火焰 | 气囊展开 (2500 FPS)、数字闹钟 (960 FPS) |
| 中帧率 (240 FPS) | 降雪 | 建筑爆破 (240 FPS) |
| 机械/周期运动 | 齿轮 | 缝纫机 |
| 自然现象 | 火焰、降雪 | 水滴 |
| 极端亮度变化 | — | 电击击穿 |
| LED/显示器刷新 | — | 数字闹钟、翻转点阵 |

### 人工校对要点

1. 用 OpenCV 逐帧解码，确认相邻帧内容不重复（排除发布端补帧）。
2. 用帧数除以拍摄帧率重算物理时长，确认 > 1 s。
3. 检查场景切换（尤其 S21 合集），必要时先裁剪再转换。
4. 核对 Commons 页面的当前许可证与作者署名，按 source.txt 规范记录。
5. 转换时恢复真实时间基准并缩放到 640x360，参照已有 source.txt 的处理说明。

## 使用注意事项

1. 从 Wikimedia Commons 下载的慢放视频需要恢复原始时间基准（参考已有 source.txt）
2. 每段素材需编写对应的 `source.txt`，记录来源、许可证和本地处理步骤
3. 使用前应验证视频帧是否真实采集，而非通过插帧生成
4. 大分辨率视频建议缩小到 640x360 以加快处理速度
5. Videezy 素材需仔细检查许可证类型，部分要求署名或仅限编辑用途
